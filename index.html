🔧 Conectar ao Supabase
Configure uma vez e seu progresso (PDI e concursos) fica salvo na nuvem — acesse de qualquer dispositivo. Opcional: você pode pular e usar só neste navegador.
Passo 1 — Criar projeto no Supabase Acesse supabase.com → login → New project → nome (ex: estudos-study) → senha → Create new project. Aguarde ~2 min.
Passo 2 — Criar tabela (SQL Editor) No painel → SQL Editor → cole e rode:
create table public.progress ( id uuid primary key default gen_random_uuid(), user_id uuid references auth.users(id) on delete cascade not null, data jsonb not null default '{}', updated_at timestamptz default now() ); alter table public.progress enable row level security; create policy "own data" on public.progress using (auth.uid() = user_id) with check (auth.uid() = user_id);
Passo 3 — Pegar as credenciais Project Settings → API → copie Project URL e anon public key.
