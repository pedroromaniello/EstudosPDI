Configure uma vez e seu progresso fica salvo na nuvem — acesse de qualquer dispositivo.
Passo 1 — Criar projeto Passo 2 — Criar tabela Passo 3 — Colar chaves
Passo 1 — Criar projeto no Supabase Acesse supabase.com → faça login → clique em New project → dê um nome (ex: pdi-study) → defina uma senha → clique em Create new project. Aguarde ~2 min.
Passo 2 — Criar tabela (SQL Editor) No painel do projeto, clique em SQL Editor no menu lateral → cole o SQL abaixo → clique em Run:
create table public.progress ( id uuid primary key default gen_random_uuid(), user_id uuid references auth.users(id) on delete cascade not null, data jsonb not null default '{}', updated_at timestamptz default now() ); alter table public.progress enable row level security; create policy "own data" on public.progress using (auth.uid() = user_id) with check (auth.uid() = user_id);
Passo 3 — Pegar as credenciais No menu lateral → Project Settings (ícone de engrenagem) → API → copie:
• Project URL → deve ser assim: https://xyzxyz.supabase.co
• anon public key → começa com eyJhbGciOi... (é longa, uns 200 caracteres)
